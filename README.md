# CAN 2.0B Controller

Synthesizable CAN 2.0B controller with APB3 host interface.

## Contents

- `Design_Files/` – RTL Design Files
- `Simulation/` – Testbench and Simulation Log
- `Lint_CDC/` – Lint/CDC scripts and reports
- `Synthesis/` – SDC, scripts
- `Netlist/` – Mapped netlist
- `Spec/` – Spec and diagrams

## Features

Standard/extended frames, bit timing, stuffing, CRC-15, arbitration, error handling, fault confinement, loopback/listen-only. Async `PCLK`/`CAN_CLK` CDC.
